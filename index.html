CASO DE ESTUDIO

¿Qué se está modelando?

Modelo hipotético

Una empresa tecnológica debe distribuir recursos financieros entre cuatro áreas interdependientes. El sistema Ax = b representa un modelo lineal simplificado: la matriz A describe las relaciones entre áreas, el vector b contiene los valores de entrada y el vector x representa la asignación estimada.

01 · Matriz A

Representa las ponderaciones propias y las interdependencias hipotéticas entre las áreas.

02 · Vector b

Contiene los valores de entrada utilizados para calcular la distribución financiera.

03 · Vector x

Contiene la asignación estimada para cada área, expresada en miles de bolivianos.

Los valores son sintéticos y se utilizan para demostrar los métodos numéricos. No representan el presupuesto real de una empresa.

FUNDAMENTO

Conclusiones generales

La solución de Gauss sirve como referencia para evaluar la precisión de GC y GCP. El residuo relativo permite comprobar cuánto satisface la solución aproximada al sistema original.

El precondicionamiento de Jacobi puede mejorar el condicionamiento numérico cuando existen escalas distintas. Sin embargo, la reducción de iteraciones debe verificarse con los resultados; no está garantizada en todos los casos.

En el desafío financiero, estos cálculos permiten comparar distribuciones hipotéticas de recursos. Para tomar decisiones empresariales reales se necesitarían datos observados, restricciones presupuestarias y criterios de negocio.
